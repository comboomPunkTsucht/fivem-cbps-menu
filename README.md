The premium administration, race, and communication tool for **comboom.sucht**. Built entirely in **C#** for maximum performance and reliability.

## 🌟 Overview

**comboom.sucht menu** replaces legacy Lua-based menus with a robust, type-safe C# implementation. It features a sleek interface designed with the **Nord Color Palette**, ensuring a cohesive and premium visual experience.

Key capabilities include a fully synchronized **Multiplayer Race System**, integrated **Voice & Radio Management** (via pma-voice/pma-radio), and comprehensive **Player Administration** tools.

## ✨ Key Features

- **Race System**: Create, save, and race on custom tracks with friends. Fully server-synchronized.
- **Voice & Radio**: Integrated control for `pma-voice` proximity and `pma-radio` channels directly from the menu.
- **Administration**: complete player management suite (Kick, Teleport, Spectate) secured by ACE permissions.
- **Nord Theme**: A consistent, eye-pleasing aesthetic (`Nord11` Red for Voice, `Nord14` Green for Online Players).

- **[pma-radio](https://github.com/AvarianKnight/pma-radio)**: For radio frequency management.
