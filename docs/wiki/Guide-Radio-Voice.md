# Guide: Radio & Voice

**comboom.sucht menu** integrates seamlessly with `pma-voice` and `pma-radio` to provide a unified communication interface.

## 🎙️ Voice Proximity

Control how far your voice travels in-game.

1. **Open Menu**: Press `F1` and go to **Voice Options**.
2. **Select Range**:
   - **Whisper (3m)**: Use for private conversations.
   - **Normal (10m)**: Standard range for most interactions.
   - **Shout (25m)**: Use when speaking to a crowd or across a street.

_Shortcut_: You can also cycle ranges using the configured keybind (Default: `Left Alt`).

## 📻 Radio Channels

Join secure radio channels for team communication.

### Prerequisites

> [!IMPORTANT]
> The resource **`pma-radio`** must be started on the server for these features to work.

### Connecting

1. Go to **Voice Options** -> **Radio Channel**.
2. Select a pre-defined channel (1-10) or choose **Custom Frequency**.
3. **Volume**: Adjust the radio volume utilizing the slider in the menu.

### Troubleshooting

**"Radio Not Connecting"**

- Ensure you have a radio item (if your server requires items).
- Check if `pma-radio` is running in the server console.
- Verify you are not in a dead zone (if applicable).
